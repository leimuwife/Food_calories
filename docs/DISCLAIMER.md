# 免责声明

## 一、数据来源说明

本小程序中展示的食物营养数据主要来源于：
- 《中国食物成分表》（公开发行版本）
- 国内外公开营养数据库
- 第三方营养 API（如 USDA FoodData Central）

所有数据均为**参考值**，实际营养成分可能因食材品种、产地、季节、烹饪方式等因素产生较大差异。

---

## 二、使用声明

1. **不构成医疗建议**：本工具提供的热量计算、营养素分析、饮食建议等功能仅用于**日常饮食参考**，不构成任何形式的医疗诊断、处方或治疗建议。

2. **个体差异**：每个人的身体状况、代谢水平、健康状况各不相同，工具中默认的营养目标（如每日2000千卡）为通用参考值，用户应根据自身情况在医生或注册营养师指导下设置个性化目标。

3. **计算精度**：系统基于「蛋白质×4 + 碳水化合物×4 + 脂肪×9」公式估算热量，此公式为国际通用简化算法，实际食物热量可能因食物基质效应略有偏差。所有数值保留合理精度，仅供趋势参考。

4. **特殊人群**：孕妇、哺乳期女性、儿童、老年人、慢性病患者等特殊人群的营养需求与常人不同，请在使用本工具前咨询专业医疗人员。
